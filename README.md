# Queuti 🦉

Personal job-application tracker + market intelligence platform.

**Stack:** Next.js (React) · MongoDB Atlas · Upstash Redis · browser-based ML (Transformers.js) · Vercel
**UI/UX:** Skeuomorphism — tactile, realistic, physical-feeling interface.

Built incrementally by autonomous build agents (see PLAN.md + GitHub issues for the task queue).
